# 分期与贷款还款时间表

单文件 HTML 的月度还款时间表 —— 把信用卡分期与贷款的**每一期**展开到「到期还款日」，再按月汇总，看清未来一年每月到底要还多少。

## 页面内容

| 模块 | 说明 |
|---|---|
| 关键指标 | 未来 12 个月合计、月均、峰值月、最近一笔待还 |
| 月度构成图 | 堆叠柱状图，区分贷款 / 汽车分期 / 账单分期，附月均参考线 |
| 逐月金额表 | 12 个月的分类明细与合计 |
| 分期档案 | 每笔分期的月供、期数进度、待还期数与剩余金额、还清日期 |
| 逐笔明细 | 可展开到每一期（还款日 / 期次 / 金额） |
| 还清时间线 | 各笔分期的结清顺序 |

## 口径

- 按**到期还款日**归月（即实际现金流出月份），而非账单记账月。
- 随信用卡账单的分期在账单月次月 7 日还款；独立分期按各自约定日还款。
- 已出账期次取自账单实据，未出账期次按期次规律推演。

## 特点

- 单文件、零外部依赖、断网可开
- 响应式：手机 390px 与桌面 1100px 均适配
- 暗色金融风，图表为手写内联 SVG
